A robust, web-based platform built to simplify student administration at **Wolaita Sodo University (WSU)**. 🏫

---

## 📝 Project Overview
This system serves as a digital bridge between students and the university administration. It automates course registration, profile management, and department-based enrollment, ensuring a seamless academic experience. 🚀

## ✨ Key Features
* **👤 Student Portal:** Easy registration and personal profile management.
* **🔐 Role-Based Access:** Dedicated interfaces for Students and Administrators.
* **📚 Course Catalog:** Comprehensive management of courses and credits.
* **🛡️ Strict Validation:** Automated checks to ensure students only enroll in relevant department courses.
* **📊 Admin Dashboard:** Powerful control panel to manage student records and enrollment status.
* **💻 Responsive UI:** Clean design optimized for desktop and tablet usage.

## 🛠️ Technical Stack
* **Backend:** Java Server Pages (JSP)
* **Database:** MySQL
* **Application Server:** Apache Tomcat
* **Frontend:** HTML5, CSS3, JavaScript
